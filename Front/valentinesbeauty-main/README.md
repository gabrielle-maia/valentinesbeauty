# Bella Beauty — Expo SDK 57

Versão corrigida do aplicativo. O login aceita o Super Admin de demonstração e também contas criadas pelo cadastro durante a sessão.

## Rodar
```bash
npm install
npx expo start --clear
```
Para navegador:
```bash
npx expo start --web
```
Para iPhone:
```bash
npx expo start
```
